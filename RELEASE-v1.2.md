# Rez Audio Studio v1.2

Lokalni nacrt GitHub Release-a — nije objavljeno.

Rez Audio Studio je Android aplikacija za lokalno izrezivanje audio zapisa i izradu zvona.

- Engleski, bosanski, njemački, italijanski i španski; automatski izbor sistemskog jezika.
- Talasni prikaz, zumiranje, izbor raspona i preslušavanje.
- Izvoz bez ponovnog kodiranja za podržane formate, spremanje i dijeljenje isječaka.
- Prečica otvara zasebno instalirani Seal; Seal nije uključen u APK.

Android 10+, paket rs.rez.audio, verzija 1.2 (3). Licenca: Apache License 2.0.

Planirani produkcijski prilog: Rez-Audio-Studio-v1.2.apk. Certifikat: CN=Rez Audio Studio, O=Rez Audio Studio, C=BA. Produkcijski potpis i checksum još nisu pripremljeni; razvojni APK nije ovaj prilog.

Provjere: 124 Java assertions i 54 nezavisne FFmpeg provjere prošle. Prevodi i formatni parametri pet jezika provjereni. Testovi uređaja i vizuelni pregled ostaju otvoreni. Xiaomi 12 nije mijenjan.

Prije javne objave završiti stavke iz docs/FINAL-v1.2.md i dobiti potvrdu konkretnog produkcijskog APK-a i SHA-256.
